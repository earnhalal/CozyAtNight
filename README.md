# CozyAtNight

Warm home, better sleep, lower bills — winter nights made cozy.

A winter cozy-home guide site for readers in the US, UK and Canada:
cheapest ways to heat a room at night, better winter sleep, cozy food
and drinks, and honest winter product guides.

Static site — plain HTML/CSS, no build step. Deployed on Vercel.
No affiliate links at launch; see `disclosure.html`.
